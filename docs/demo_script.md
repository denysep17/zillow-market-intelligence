# 60–90 Second Product Demo Script

## Goal

Show one coherent decision workflow rather than every feature.

## Script

**0–10 sec — Frame the problem**

“This is Zillow Market Intelligence, a housing-market early-warning system built from public Zillow Research data. The goal is to detect changing market conditions before they are fully visible in headline home-value metrics.”

**10–25 sec — Executive Monitor**

Open **Executive Monitor**.

“The system monitors 894 U.S. metros. Each market has a current regime, a 3-month home-value forecast, an empirical uncertainty interval, and a cooling-transition probability. The priority table surfaces markets that deserve analyst attention.”

**25–50 sec — Metro Deep Dive**

Select one high-risk metro from the priority list and open **Metro Deep Dive**.

“For a selected metro, I can see the current regime, the point forecast and interval, the recent home-value path, supply conditions, and the largest Elastic Net feature contributions. These contributions are predictive explanations, not causal claims.”

**50–68 sec — Alerts**

Open **Alerts**.

“The alert threshold is treated as a product policy. The precision-oriented policy reaches about 51% precision but only 20% recall, so this is a prioritization tool rather than a deterministic warning system.”

**68–85 sec — Model Health**

Open **Model Health**.

“The product also exposes where the system is weaker: smaller metros, high-volatility periods, cooling regimes, and delayed feature availability. A one-month lag across all dynamic signals increases MAE by about 31%, so the deployment makes that limitation explicit rather than hiding it.”

**85–90 sec — Close**

“The project is designed end to end: reproducible data pipelines, leakage-safe temporal validation, uncertainty, regime modeling, failure analysis, and a live deployed decision-support product.”

## Recording notes

- Keep the mouse still while speaking each metric.
- Do not explain every chart.
- Use one metro only.
- Keep the Model Health section visible at the end.
- Aim for 80–90 seconds, not faster.
